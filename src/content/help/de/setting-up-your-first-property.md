Ownia ist ein Website-Baukasten für Eigentümer von Ferienwohnungen, der Direktbuchungen ermöglicht. Bevor Gäste direkt bei Ihnen buchen können, müssen Sie mindestens eine Unterkunft hinzufügen. Diese Anleitung führt Sie Schritt für Schritt durch den gesamten Prozess.

## Den Onboarding-Assistenten starten

Wenn Sie gerade Ihr Ownia-Konto erstellt haben, werden Sie automatisch durch einen 5-stufigen Einrichtungsprozess geführt: Einrichtung der Organisation, Immobilienquelle, Fotos und Beschreibung, Preisgestaltung und Veröffentlichung. Sie können jederzeit „Jetzt überspringen“ auswählen und die Einrichtung später auf der Seite „Immobilien“ abschließen.

## Eine Unterkunft manuell hinzufügen

Um jederzeit eine Unterkunft hinzuzufügen, öffnen Sie die Seite **Unterkünfte** in der Seitenleiste und klicken Sie auf **Unterkunft hinzufügen**. Sie werden aufgefordert, einen von zwei Ausgangspunkten auszuwählen:

- **Von Grund auf neu erstellen** – Erstellen Sie Ihren Eintrag anhand eines leeren Formulars.
- **Aus der Angebots-URL importieren** – Fügen Sie einen Link zu einem bestehenden Eintrag auf Airbnb ein, und Ownia ruft automatisch die Fotos, die Beschreibung und die Ausstattungsmerkmale ab.

Wenn Sie Daten über eine URL importieren, überprüfen Sie den Bildschirm **Ergebnisse importieren** sorgfältig. Felder, die Ownia nicht erkennen konnte, sind gekennzeichnet, sodass Sie diese selbst ausfüllen können, bevor Sie fortfahren.

## Angaben zur Immobilie eingeben

Egal, welchen Weg Sie wählen, Sie gelangen immer zum Formular **Neue Immobilie**. Sie sollten mindestens folgende Einstellungen vornehmen:

- Name und Art der Immobilie (Wohnung, Haus, Villa usw.)
- Eine kurze und eine ausführliche Beschreibung
- Fotos – das erste Foto wird zu Ihrem Titelbild
- Ausstattung
- Hausordnung und An- und Abreisezeiten
- Grundpreis pro Übernachtung

Wenn Sie mit den Angaben zufrieden sind, klicken Sie auf **Unterkunft erstellen**.

## Wie geht es weiter?

Sobald eine Unterkunft angelegt wurde, erscheint sie in Ihrem Ownia Web Store – Ihrer eigenen, mit Ihrem Markenzeichen versehenen Buchungswebsite. Von dort aus können Sie:

- [Stripe verbinden](/de/connecting-stripe-to-accept-payments/), damit Gäste direkt an Sie bezahlen können.
- [Synchronisieren Sie Ihren Kalender](/de/syncing-calendars-via-ical/) mit Airbnb und Booking.com, um Doppelbuchungen zu vermeiden.
- Passen Sie Preise, Stornierungsbedingungen und Buchungsregeln auf der Detailseite der Unterkunft an.

Sie müssen nicht alle Einstellungen gleich am ersten Tag vornehmen – mit Ownia können Sie ein Objekt veröffentlichen und es im Laufe der Zeit nach und nach optimieren. Das Einzige, was Sie benötigen, bevor Sie eine bezahlte Buchung annehmen können, ist ein verbundenes Stripe-Konto. Darauf geht die nächste Anleitung ein.
